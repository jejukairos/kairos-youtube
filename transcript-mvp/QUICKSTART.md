# 이제 이렇게 사용하세요

**2026-10-21부터 새 방식의 예약 감시를 켰습니다.** 현재 등록된 36개 채널을 한국 시간 **11:00·16:00·21:00**, 하루 세 번 확인하고,
이 채팅의 Codex 모델이 자막 전체를 읽어 요약한 뒤 Telegram으로 보냅니다. YouTube Data API·Gemini API는 사용하지 않습니다.
PC와 Codex 앱이 켜져 있어야 하며 이 계정의 사용 한도를 사용합니다. 아래 직접 수집 방법은 수동 이용 시 참고하세요.

지금은 한 번에 최대 8편·자막 본문 합계 12만 자까지 준비합니다. 계정 사용량 70%에서 경고하고 90% 이상이면 신규 분석을 보류합니다.
별도로 요청한 미발송 127편은 42·42·43편으로 나눠 배정했습니다. 이 작업은 계정 사용량 80%에서 신규 분석을 보류하고 남은 영상을 이월합니다.
첫 시작 목표는 10월 21일 밤 9시이며 자막 접속 제한이 계속되면 연기될 수 있습니다. 세 번에 전부 발송된다는 보장은 아닙니다.
이미 보낸 영상은 건너뛰고, 남은 영상·접근 실패 영상은 보존합니다. 정각에 모든 요약이 동시에 도착한다는 뜻은 아닙니다.
채널을 조정하고 싶으면 이 Codex 대화에 채널명을 알려주세요. 자동으로 채널을 삭제하지 않습니다.

이 프로그램은 **YouTube Data API 키·Gemini API 키 없이** 공개 자막을 수집합니다.
유료 자막 서비스나 유료 프록시는 사용하지 않습니다.

**로컬 AI 모델은 설치되어 있지 않지만, 예약된 이 대화의 모델이 요약을 맡습니다.**
새 영상 자막을 직접 모아 보내실 필요는 없습니다. 별도 영상 링크나 이미 가진 자막을 이 대화에 보내는 수동 이용도 가능합니다.
이 대화의 요약은 기존 Codex 계정의 사용 한도를 사용하며 무제한 무료 API가 아닙니다.

## 1. 링크를 모으세요

이 폴더의 `urls.txt`를 열어 영상 링크를 한 줄에 하나씩 넣고 저장합니다.
같은 영상을 여러 번 넣어도 한 번만 수집합니다.
처음에는 한 번에 3~5개로 시작하세요. 이것은 서비스 보장 한도가 아닌 편의를 위한 권장치입니다.

```text
https://www.youtube.com/watch?v=L2GG_DeUDa0
https://youtu.be/n6nO1MkYId0
https://www.youtube.com/watch?v=QslXeEZ0tPI
```

## 2. 자막을 받으세요

현재 개발 PC는 설치를 끝냈습니다. Windows에서는 `collect-captions.cmd`를 두 번 클릭합니다.
이 동작은 자막 수집만 하며 요약이나 Telegram 발송을 자동 실행하지 않습니다.

결과는 `transcripts` 폴더에서 확인하세요.

- `영상ID.txt`: 읽기 쉬운 시간 표시 자막. 이 파일을 이 대화에 보내면 됩니다.
- `영상ID.json`: 언어·자동자막 여부·시간·원문을 보존한 데이터.
- `index.json`: 영상별 성공/실패 결과. 한 편이 실패해도 다음 영상을 계속 시도합니다.

이미 받은 영상은 `CACHED`로 표시하고 재수집하지 않습니다.
자막을 새로 받으려면 개발자용 명령의 `--force` 옵션을 사용합니다.

## 3. 이 대화에 자막을 보내세요

`txt` 파일을 첨부하고 “투자 영상 요약해줘”라고 적어주세요.
채널명·제목·원본 URL·자막 시간 표시가 함께 들어갑니다.
표나 차트가 자막에 없으면 중요한 화면도 함께 보내주면 좋습니다.

## 4. Telegram 발송

프로그램에는 근거 검사를 통과한 요약만 발송하는 기능이 있습니다.
기본 실행은 미리보기이고 `--send`를 명시한 경우에만 실제 전송합니다.
중요도 3~5만 발송하고, 중요도 5는 더 긴 심층 요약을 요구합니다.
중요도는 내부 선별용이며 매수 추천·수익률 점수가 아닙니다. 메시지에 별점은 표시하지 않습니다.
발송은 원본 링크 카드 → `📊 제목`과 `▶️ 핵심 문단` 순서입니다.
근거 시간·분류표는 본문에서 빼고 내부 검토 자료에 보관합니다.

기존 GitHub 봇 Secrets를 사용하는 별도 **수동 전용** 발송 경로도 연결했습니다.
이 발송 경로 자체는 수집이나 AI를 실행하지 않습니다. 수집·요약은 별도의 Codex 채팅 예약이 맡습니다.
이전 Gemini 방식의 예약 workflow는 계속 중지 상태입니다.
이 대화에 자막을 붙여넣는 것만으로 Telegram에 자동 발송되지는 않습니다.

비밀키를 이 대화에 붙여넣지 마세요. 로컬 발송을 쓸 때만 `.env.example`을 `.env`로 복사하고
`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`를 로컬 파일에서 입력합니다.
GitHub Secrets에 보관된 값은 이 프로그램이 내려받을 수 없습니다.

## 실패하면 무슨 뜻인가요?

| 표시 | 뜻과 대응 |
|---|---|
| `IP_BLOCKED`, `RATE_LIMITED` | YouTube가 접속을 제한했습니다. 반복 호출을 멈추고 나중에 재시도하세요. |
| `NO_CAPTIONS` | 공개 자막이 없습니다. 본인이 가진 자막을 가져올 수 있습니다. |
| `AGE_RESTRICTED`, `ACCESS_RESTRICTED`, `UNAVAILABLE` | 접근 제한·삭제 등의 이유로 건너뛰었습니다. 로그인이나 쿠키로 우회하지 않습니다. |
| `SKIPPED / NO_LOCAL_AI_MODEL` | 자동 요약용 로컬 AI가 없습니다. 원본 자막은 그대로 보존됩니다. |
| `LOCAL_CONTEXT_TOO_LARGE_USE_MANUAL_PACKET` | 로컬 모델의 안전 입력 길이를 넘었습니다. 자막을 자르지 않고 수동 요약을 기다립니다. |
| `RETRY`, `WAITING_RETRY` | Telegram이 안내한 대기 시각 후 같은 명령을 다시 실행합니다. 이미 보낸 부분은 재발송하지 않습니다. |
| `UNCERTAIN` | 메시지가 도착했는지 불확실합니다. 자동 재발송을 막았습니다. 먼저 Telegram에서 확인하세요. |

PC를 끄거나 절전 상태로 두면 로컬 수집·로컬 AI는 실행되지 않습니다.
오늘 성공했다고 모든 영상과 다른 장소에서도 계속 성공하는 것은 아닙니다.
