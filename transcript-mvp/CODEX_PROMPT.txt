프로젝트: Kairos YouTube Intelligence — 무료 자막 수집 → 투자 콘텐츠 요약 → 텔레그램 전송.

첨부된 batch_transcripts.py / urls.txt / requirements.txt 기반으로 작동하는 MVP를 구현하라.

필수 조건:
1. 외부 유료 서비스, 과금 가능한 API 및 체험 종료 후 유료 전환은 절대 사용하지 않는다. 새 유료 서비스/API 가입이나 결제 정보 입력을 요청하지 않는다. 기존 ChatGPT/Codex 플랜도 무제한/무료 API로 간주하지 않는다.
2. urls.txt에 영상 URL 여러 줄 입력 또는 간단한 로컬 입력 폼/CLI 인자로 묶음 입력을 지원한다. 각 URL을 정규화하고 video_id로 중복 제거한다.
3. youtube-transcript-api로 수동 자막 우선, 자동 생성 자막 차선 추출. 한국어, 영어, 일본어 우선. 타임스탬프, 원문 언어, 자동생성 여부, 영상 URL을 포함한 JSON/TXT 로컬 파일 저장.
4. 실패 시 IP_BLOCKED, NO_CAPTIONS, AGE_RESTRICTED, UNAVAILABLE 등으로 구분하며 전체 배치를 중단하지 않는다. yt-dlp의 자막 전용 수집을 적법한 대체 경로로 검토한다. 우회가 필요한 인증/지역 제한 영상은 건너뛰고 보고한다.
5. 자막이 제공되지 않는 경우 로컬 Whisper/faster-whisper 오프라인 전사 가능성을 독립적인 옵션으로 설계한다. 원본 영상/음성 접근 권한과 저작권, 컴퓨터 성능을 확인하기 전에는 자동 실행하지 않는다.
6. 요약 로직은 원문 증거에 기반하며 실제 발언, 수치, 기업명, 전망, 조건, 반론, 확인할 데이터, 시간 정보를 구분한다. 영상 내 주장과 검증된 사실을 혼동하지 않는다. 최소 3개 근거 없이는 과장된 투자 결론을 만들지 않는다. AI 모델이 제공되지 않으면 요약 단계는 SKIPPED로 보고하고 원본 자막 파일은 보존한다.
7. 2026-10-21 최신 사용자 요청: config/monitor.json의 delivery_policy=all_selected를 적용한다. 사용자가 선택한 채널·프로그램·인물 조건에 맞는 영상은 중요도나 단순 내용, 서로 다른 URL 간 비슷한 내용만으로 제외하지 않는다. 같은 video_id의 중복 발송만 방지한다. 원문 근거 검사는 유지하고 자막·계정 한도 문제는 보류로 추적한다.
8. 기존 사용자 Telegram Bot API 토큰과 chat_id를 .env/환경변수로만 설정한다. 로그·Git·텔레그램 메시지에 비밀값을 절대 출력하지 않는다. 메시지 4096자 제한 분할, 전송 실패 시 재시도, 동일 video_id 중복발송 방지.
9. 출력 예시: '📊 영상 제목 / ▶️ 핵심 주장 및 실제 숫자 / ▶️ 수혜·리스크 / ▶️ 하워드 막스 관점의 2차적 사고 / ★ 중요도 / 🔗 원본 링크'. 맥락·비판·추정·원문 발언 구분.
10. 먼저 자막 추출 기능을 테스트하고, 이후 요약, 이후 텔레그램 순서로 각 단계 별도 검증. 외부 유료 API 없이 완전자동 요약이 가능한 환경인지 검증하여 불가능하면 무리하게 구현하지 말고 명시.
11. 실행 매뉴얼은 휴대폰에서 보기 쉬운 한국어로 정리한다. Windows/macOS/Linux 범용을 우선하되 PC가 꺼진 상태에서는 로컬 작업이 실행되지 않는다는 사실을 명시한다.
12. 시작은 입력 URL https://www.youtube.com/watch?v=L2GG_DeUDa0 로 하되 자막 수집 성공 여부를 실제로 검증하고 허위 성공 표시 금지.
